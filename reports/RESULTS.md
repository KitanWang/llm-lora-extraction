## 九、结论

- **Qwen2.5-1.5B / IID**：全字段准确率 12.5% → 87.5%（+75.0 pp）；Schema 合规率 60.5% → 100.0%
- **Qwen2.5-1.5B / OOD**：全字段准确率 7.3% → 80.7%（+73.3 pp）；Schema 合规率 70.7% → 99.3%
- **Qwen2.5-7B / IID**：全字段准确率 22.5% → 93.0%（+70.5 pp）；Schema 合规率 97.0% → 100.0%
- **Qwen2.5-7B / OOD**：全字段准确率 15.3% → 91.3%（+76.0 pp）；Schema 合规率 93.3% → 100.0%
- **Qwen2.5-1.5B 泛化差距**：微调后在未见模板族上全字段准确率下降 6.8 pp（87.5% → 80.7%），说明模型学到的不只是模板记忆。
- **Qwen2.5-7B 泛化差距**：微调后在未见模板族上全字段准确率下降 1.7 pp（93.0% → 91.3%），说明模型学到的不只是模板记忆。
