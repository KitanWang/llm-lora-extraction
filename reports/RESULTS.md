# 实验结果：基座模型 vs LoRA/QLoRA 微调后

> 所有指标在同一套评测集、同一套 prompt、**贪心解码**（`do_sample=False`）下取得，可复现。

## 九、结论

- **Qwen2.5-1.5b / IID**：全字段准确率 12.0% → 87.0%（+75.0 pp）；Schema 合规率 66.5% → 100.0%
- **Qwen2.5-1.5b / OOD**：全字段准确率 6.7% → 67.3%（+60.7 pp）；Schema 合规率 71.3% → 100.0%
- **Qwen2.5-1.5b 泛化差距**：微调后在未见模板族上全字段准确率下降 19.7 pp（87.0% → 67.3%），说明模型学到的不只是模板记忆。
